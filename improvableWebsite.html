Why is drudgereport.com a bad designed website

The drudgereport.com is a bad website because it does not have consistency and ease of navigation. The web page looks very mess and there is no consistent page layout. The page contains many links but these links are all stacked together, making the links hard to understand and navigate. Furthermore, the fonts the website uses are very different, which makes the page looks ugly, and the position where advertises appear is random.
